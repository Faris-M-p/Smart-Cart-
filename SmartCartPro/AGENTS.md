# Project instructions

## Git operations

- Make the requested code and project-file changes only.
- Do not create, switch, rename, or delete branches.
- Do not commit, amend, cherry-pick, merge, rebase, reset, stash, or otherwise change Git history or repository state.
- Do not stage files or run commands that write to Git metadata.
- Read-only Git commands, such as `git status` and `git diff`, are allowed when needed to understand or report the work.
- Leave the changes in the working tree for the user to review and commit themselves.
